## 💡 概念起源与设计哲学 (The Core Concept)

传统自动化建造类游戏（如《异星工厂 Factorio》、《戴森球计划 Dyson Sphere Program》、《幸福工厂 Satisfactory》）的物流基石是**刚性轨道与传送带（Conveyor Belts）**。玩家在离散网格上铺设输送带、分流器与机械臂，物料以确定性的线性方式位移。

**Flux Factory（通量工场）** 探索一种截然不同的自动化流体范式：**彻底抛弃实体传送带，完全依赖「连续物理场」操纵自由粒子流**。

在无轨物理场中：
- 物流线不再是一条固定的履带，而是一股在电磁与引力场中翻滚、折射、共振的**高能粒子流河流**。
- 空间调度需要调动经典力学与电动力学直觉：利用**引力弹弓**实现大角度变轨，利用**洛伦兹力**实现自然正负电荷分离，利用**托卡马克对撞环**在交汇点触发聚变，利用**阻尼线圈**平抑过剩动能。
- 系统的瓶颈不再是皮带带速，而是流体力学中的通量（Throughput）、层流稳定性、碰撞动能共振窗口与电网功率承载。

## ⚡ 核心物理机制与场节点 (Physics & Fields)

本项目基于纯原生 Canvas 2D 与自研显式动力学积分核实现，所有相互作用均遵循解析物理规律：

```
                    ┌─────────────────────────┐
                    │   α(+) / β(-) 束流发射源 │
                    └────────────┬────────────┘
                                 │
                   ┌─────────────┴─────────────┐
                   ▼                           ▼
        ┌─────────────────────┐     ┌─────────────────────┐
        │  引力井 (Gravity)   │     │  洛伦兹环 (Lorentz) │
        │  F = G·M / (r² + ε²) │     │  F = q · (v × B)    │
        │  全局吸引、轨道弯折   │     │  按电荷极性相反折弯  │
        └──────────┬──────────┘     └──────────┬──────────┘
                   │                           │
                   └─────────────┬─────────────┘
                                 ▼
                    ┌─────────────────────────┐
                    │  托卡马克对撞加工环 (C) │
                    │  α(+) + β(-) ──> γ(0)   │
                    │  共振能级窗口: 1.8~5.2  │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │    γ 高能等离子交付货舱  │
                    │   3.0s 滑动窗口吞吐率计量 │
                    └─────────────────────────┘
```

1. **引力井 (Gravity Well / G - 12 MW)**：
   - 势场公式：$F = \frac{P}{r^2 + \epsilon^2}$（$\epsilon^2 = 400$ 软化因子，消除 $r \to 0$ 奇点发散）。
   - 作用：吸引所有流经粒子，可构建类似天体物理中“引力弹弓（Gravitational Slingshot）”的无损变轨航道。
2. **斥力场 (Repulsor Field / R - 10 MW)**：
   - 势场公式：$F_{\text{rep}} = -\frac{P}{r^2 + 200}$。
   - 作用：排斥粒子，用于为脆弱设施构建安全缓冲屏障，或实现高速分流。
3. **洛伦兹偏转环 (Lorentz Field / L - 15 MW)**：
   - 动力学方程：$\vec{F} = q \cdot (\vec{v} \times \vec{B})$。
   - 严格保证洛伦兹力做功为零（$\vec{F} \cdot \vec{v} \equiv 0$），维持粒子速率标量恒定。正电荷（$\alpha^+$）向顺时针偏转，负电荷（$\beta^-$）向逆时针偏转，电中性产物（$\gamma^0$）无感直线穿透。
4. **阻尼减速线圈 (Viscous Dampener / D - 8 MW)**：
   - 粘性阻尼：$\vec{F} = -c \vec{v}$。
   - 作用：平抑过高粒子动能，防止粒子因速度过大逃逸出捕获漏斗或超临界撞碎。
5. **增压加速导轨 (Booster Rail / B - 14 MW)**：
   - 矢量推力：$\vec{a} = a_0 \cdot \hat{u}(\theta)$。
   - 作用：为粒子流注入指定方向的脉冲冲量，克服阻力或穿透低速屏障。
6. **托卡马克对撞环 (Tokamak Collider / C - 25 MW)**：
   - 核心生产设备！当 $\alpha^+$ 与 $\beta^-$ 粒子在此汇聚，引发对撞聚变，生成高能中性 $\gamma^0$ 粒子或超阶 $\Omega$ 粒子！
   - 严格遵守电荷守恒（$+1 + (-1) = 0$）与动量守恒定理。

## 🎯 深度策略与硬核冲突机制 (Game Mechanics & Depth)

1. **动能共振窗口 (Kinetic Resonance Window)**：
   - 对撞并不是碰到了就能合成：两束粒子的入场平均速率必须落在**共振能量窗口 ($1.8 \le v \le 5.2$)** 内！
   - **亚临界散射 (Subcritical Bounce, $v < 1.8$)**：能量不足以穿透库仑势垒，粒子发生弹性散射反弹弹开，伴随清脆高频金属音；
   - **超临界撞碎 (Supercritical Shatter, $v > 5.2$)**：冲击动能超过核结合力，粒子撞碎为无用热辐射火花碎片，伴随破裂炸音；
   - **共振聚变 (Resonant Fusion)**：完美配速，聚变中性紫色高能等离子！
2. **电网功率容量与欠压震荡 (Power Grid & Brownout)**：
   - 每一座部署的设施均需消耗实时电网功率（MW）。
   - 关卡存在额定功率预算上限（如 65 ~ 110 MW）。
   - 当玩家无脑铺设设施导致总功率超额时，电网将陷入**欠压过载震荡 (Brownout)**：全场力场输出瞬间衰减 **45%** 并触发蜂鸣报警，迫使玩家优化管线、精简拓扑！
3. **欧米伽超粒子半衰期 (Unstable Omega Particles & Half-Life)**：
   - 双阶对撞（$\gamma + \gamma$）可合成高阶金色欧米伽等离子（$\Omega$）。
   - $\Omega$ 具有严格的**放射性半衰期 (约 3.3 秒)**，在真空中飞驰时脉搏光环加速闪烁，若未在倒计时结束前入港将剧烈湮灭！必须搭建磁轨极速通道。
4. **副产物分离与货舱防污染 (Byproducts & Contamination Gate)**：
   - 高阶对撞会伴生副产物高能正电子（$\pi^+$）。
   - 若副产物误入目标货舱，会触发**“货舱污染警报”**，导致货舱吞吐停滞 1.5 秒！
   - 玩家必须利用洛伦兹磁场在下流完成中性产物（$\gamma^0$ 直通）与带电副产物（$\pi^+$ 偏折）的自然物理分选。

## 🎮 八大关卡战役体系 (Campaign Levels)

- **Level 1: 引力弹弓 (Gravitational Slingshot)**
  - 任务：使用引力井将单股粒子束弯折绕过阻挡物，送入上方货舱。
  - 核心考验：轨道偏转角计算与能量平衡。
- **Level 2: 洛伦兹电荷分离 (Lorentz Separation)**
  - 任务：中央发射混杂束($\alpha^+$ / $\beta^-$)，利用洛伦兹环将正负电荷分流至上下双仓。
  - 核心考验：电动力学非对称偏转布局。
- **Level 3: 托卡马克能级共振 (Resonance Chamber)**
  - 任务：将上下两路粒子导向对撞环，控制速度在 1.8~5.2 区间实现聚变并送达终点。
  - 核心考验：速度区间调谐与相位交汇。
- **Level 4: 减速入港 (The Arrestor)**
  - 任务：面对超高速发射束，架设阻尼线圈吸收多余动能，避免超临界撞碎。
  - 核心考验：动能衰减梯度设计。
- **Level 5: 谐振母港大挑战 (Resonant Metropolis)**
  - 任务：多源产线综合调度，达成 $\ge 3.5\text{/s}$ 的持续稳定交付！
  - 核心考验：全局场域无冲突编排。
- **Level 6: 能量受限拓扑 (Power Grid Optimization)**
  - 任务：严格 65 MW 电网上限，考验用最精简设施搭建稳定流体物流。
  - 核心考验：空间紧凑性与功率预算优化。
- **Level 7: 欧米伽极速竞速 (Half-Life Sprint)**
  - 任务：制造超高阶 $\Omega$ 粒子并在 3.3 秒半衰期湮灭前极速送入奇点舱！
  - 核心考验：加速导轨喷射与时序竞速。
- **Level 8: 拓扑大统一 (The Grand Singularity)**
  - 任务：终极挑战！对撞聚变、洛伦兹副产物排污分离、85 MW 功率限制与 2.2/s 高吞吐交付！
  - 核心考验：全物理规则综合设计。
